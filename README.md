# Hospital Patient Care Analytics Pipeline

A simple end-to-end **Data Engineering** case study for a multi-specialty hospital.

## Objective

Design a data engineering pipeline that collects, cleans, integrates, stores, and analyzes hospital data to support better operational efficiency and patient care.

## Data Sources

* Patient Registration
* Appointment Scheduling
* Laboratory Reports
* Wearable Health Devices
* Doctor Consultation Notes

> The assignment does not provide a real dataset, so sample data is used to demonstrate the pipeline.

## Pipeline

```text
Hospital Data Sources
        ↓
Data Ingestion
        ↓
Data Cleaning
        ↓
Data Integration
        ↓
Data Storage
        ↓
Data Analysis
        ↓
Business Insights
```

## Analysis Covered

* Patient waiting-time analysis
* Department comparison
* Time-pattern analysis
* Basic patient-risk analysis demonstration
* Business insights and recommendations

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Project File

`Hospital_Patient_Care_Analytics.ipynb`

## Note

The patient-risk analysis is only a demonstration using sample data and is **not intended for real clinical or medical decision-making**.
